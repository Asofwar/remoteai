# 聊天对话区域展示验收（2026-09-16）

## 范围和基准

仅调整桌面 Codex GUI 聊天对话区域的展示组件及其测试。
基准为 Windows 虚拟机中已打开的 ChatGPT/Codex「运行测试」对话与 Switch 独立验收对话。
两边实际发送了相同的 Markdown 和两次 PowerShell 输出请求，并分别检查停止后的内容。

本次源码通过开发环境、生产构建浏览器回放和 Windows 虚拟机原生安装版验证。
已备份旧程序、替换本次 release 构建并重启，界面确认 Codex 已连接、本地代理运行中、手机已连接。
安装后 SHA256 与构建产物一致：`812C12A844350601D680863361DBF1ECAC5DE5865E8AE890C58C4C2CDDD514EA`。
生产代码仅涉及聊天展示组件；没有修改后端、Provider、路由、侧栏、设置或输入发送逻辑。

## 已调整的展示

| 场景 | 调整后的行为 |
| --- | --- |
| 空思考事件 | 没有可显示内容时不再出现空的活动折叠栏 |
| 处理过程 | 将耗时和过程合并为一行；执行中展开，正常完成自动收起 |
| 用户正在查看过程 | 手动展开、收起，以及已展开的命令详情在完成时保持原选择 |
| 停止和失败 | 保留此前显示的说明和输出；停止提示只出现一次，位于回复前 |
| 等待首段回复 | 单一阶段提示，不提前出现空耗时栏或重复计时 |
| 命令摘要 | 缩短已识别的 PowerShell 启动前缀；详情和复制仍保留原命令 |
| 中断的命令 | 摘要明确显示「已停止」，保留已有输出 |
| 回复复制 | 复制操作位于最终回复下方，过程说明不再重复显示复制按钮 |
| 用户消息 | 中性色圆角气泡，桌面限制阅读宽度，保留窄屏适配 |
| 用户图片附件 | 缩略图位于文字气泡上方、右对齐；多图可换行，纯图片消息没有空气泡 |
| 原图预览 | 小图保留原始尺寸，大图适应可用区域；缩放、还原与关闭继续可用 |
| Markdown | 紧凑加粗标题、横线表格、连续圆角代码块和语言标签 |
| 表格操作 | 支持复制制表符分隔文本、展开查看、横向滚动与键盘关闭 |
| diff 示例 | Markdown 的 diff/patch 围栏显示为高亮代码；实际工具修改继续使用文件差异查看器 |
| 引用浮层 | 滚动或 Escape 关闭后，延迟到达的选区事件不再重新弹出；保留选中文字及重新选择能力 |
