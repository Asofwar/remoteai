# 自定义模型目录

Remote AI 更新 `~/.codex/codex-switch-model-catalog.json` 时，会按 `slug` 匹配模型，
保留手动设置的 `apply_patch_tool_type`、`shell_type`、`base_instructions`、
其他工具能力字段以及未知字段。目录顶层的额外字段也会保留。

模型列表、名称、说明、排序、可见性、API 可用性、推理档位、上下文长度、输入类型和快速模式
仍由供应商配置决定。新模型使用默认属性，已移出供应商配置的模型不会继续出现在当前目录中。

切换供应商或供应商组前，现有模型的非托管属性会自动保存在同目录下的
`codex-switch-model-customizations.json`。再次出现相同 `slug` 时，这些属性会恢复。
直接修改当前模型目录即可；当前条目的内容优先于之前保存的属性。
删除自定义字段会清除它的保存值；程序必需的默认字段会在下次更新时补齐。

匹配使用完整 `slug`，区分大小写。供应商组的模型名包含供应商名称，重命名供应商后会视为新模型。
不同 Codex Home 的自定义属性分别保存。目录或保存文件无法读取、JSON 无效时，更新会报错，
不会用默认目录覆盖原文件。

## 默认上下文容量

普通代理模式使用官方账户时，模型单独设置的容量优先于全局值；只有未单独设置的模型才使用全局值。
例如全局为 272K、某个模型为 1000K 时，该模型使用 1000K，不会被全局值截低。

Codex GUI 的“设置 → 上下文”可分别配置各模型的默认容量，也可添加自定义模型或恢复默认。
这些设置与普通代理模式独立。当前对话的单独设置优先，其次是 GUI 的模型设置；
未配置时，官方模型使用 Admin 官方模型列表中的容量，其他模型使用供应商配置。
Admin 默认值与 GUI 自定义值分别保存，刷新列表不会覆盖用户的自定义值。
后台暂时不可用时保留已读取的默认值；首次发现模型仍使用现有的官方列表回退流程。

修改会在下次发送消息或打开对话时应用，不会中断正在运行的任务。
输入单位为 K Token（1 K = 1000 Token）；实际可用容量仍会扣除模型的预留空间。
Admin 官方模型列表原有的自动刷新行为保持不变，这些设置不构成上游服务的强制容量限制。
