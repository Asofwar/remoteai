# 手机端 Token 汇总

聊天列表右下角头像菜单提供「Token 汇总」入口。汇总是独立页面，不显示底部导航；
标题栏返回按钮和 Android 系统返回均回到原聊天，保留聊天内容和输入草稿。

统计来自当前连接的电脑，通过现有聊天连接读取。电脑端和手机端需要包含本功能的版本。
未连接或读取失败时留在汇总页，提供连接提示和刷新入口。

## 显示内容

- 所选时段的 Token 总量，以及输入、输出、推理、缓存累计。
- 官方账户额度趋势：选择或搜索账户、剩余额度或时段下降、小时／6 小时／天粒度。
- 短／长上下文消耗、普通／快速模式消耗的累计值、占比及每日变化。
- 每日热力图与 Token 趋势，支持横向滚动、点按查看数值。
- Provider、模型、账户消耗排行，以横条列表展示 PC 端相同的前 8 名。

默认周数、刷新间隔和长上下文阈值取自电脑。手机可切换 1 至 52 周的查看范围，
不修改电脑设置。排行与 PC 一样基于最近请求，而非按所选周数过滤。
额度下降沿用 PC 的计算逻辑，不将额度重置、缺失记录误算为消耗。

## 刷新与验证

统计请求保持单次在途，完成后安排下次刷新。离开页面、断线或进入后台会停止刷新；
旧请求不能覆盖新的统计范围。长时段额度图使用虚拟列表，避免一次渲染全部小时记录。

数据边界与刷新测试位于 `apps/desktop/src/remoteChat/tokenSummary.test.ts`、
`useTokenSummary.test.tsx`，额度时间对齐测试位于 `apps/native/src/tokenSummary/quotaPoints.test.ts`。

Android 回归沿用 `apps/desktop/e2e/mobile-fixture.mjs` 和只读临时模拟器，运行：

```powershell
$env:ANDROID_CHAT_DISPOSABLE = '1'
node apps/desktop/e2e/android-token-summary.mjs
```

回归覆盖头像入口、全部统计卡片、自动刷新、底部导航隐藏、读取期间返回以及系统返回。
